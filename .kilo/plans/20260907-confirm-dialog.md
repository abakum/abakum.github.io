# План: диалог подтверждения «глагол + уточнение» (LunarReturns, 07.09.2026)

## Цель

Переделать кастомный диалог подтверждения: заголовок — глагол, ниже —
уточнение; всё отцентровано. В сценариях импорта базы альтернативы
(✅/❌) — на отдельных строках, а не через запятую.

## Контекст кода

- Разметка: `LunarReturns/index.html:518-524` — `#confirmOverlay` →
  `#confirmDialog` (role="alertdialog") → `#confirmMsg` + btnrow
  (✅ `#confirmOk` / ❌ `#confirmCancel`).
- CSS: `#confirmOverlay` 392-402, `#confirmDialog` 403-411,
  `#confirmMsg` 412, `.btnrow { justify-content: center }` 413.
- JS: `confirmAuto(msg)` 1249-1258 (один текст в `#confirmMsg`),
  `closeConfirm` 1259-1264; Escape-обработчик 2989.
- Вызовы `confirmAuto` (10 шт.): 1379 (удаление записи), 2113 (очистка
  базы), 2148 / 2609 / 2709 (импорт базы: объединить/заменить — три
  пути: вставка из буфера, миграция ВК-облака, передача базы по цепочке),
  2216 (отзыв согласия на пуши), 2330 / 2339 (удаление ПДн из облаков).

## Изменения

1. **Разметка** (index.html:519-521): над `#confirmMsg` добавить
   `<div id="confirmTitle"></div>`.
2. **CSS**:
   - `#confirmDialog { text-align: center; }` — весь контент отцентрован;
   - `#confirmTitle { font-weight: 600; margin-bottom: 4px; }`;
   - `#confirmMsg`: добавить `white-space: pre-line` (перенос строк `\n`
     → отдельные строки для альтернатив импорта) и приглушение
     `color: var(--muted)`; `margin-bottom: 10px` остаётся.
3. **JS** — сигнатура `confirmAuto(title, detail)`:
   ```js
   function confirmAuto(title, detail) {
       return new Promise(resolve => {
           document.getElementById("confirmTitle").textContent = title;
           const msg = document.getElementById("confirmMsg");
           msg.textContent = detail || "";
           msg.style.display = detail ? "" : "none";
           ...
       });
   }
   ```
   `closeConfirm` и Escape-обработчик не меняются.
4. **Обновление всех 10 вызовов** (тексты — предложение, легко правятся):
   - 1379: `("Удалить", db[i].n + " " + db[i].d + "?")`
   - 2113: `("Удалить", "ВСЕ записи (" + db.length + ")")`
   - 2148 / 2609 / 2709 (импорт базы, альтернативы на разных строках):
     `("Импорт", "✅ — объединить (" + incoming.length + " зап.)\n❌ — заменить текущую базу")`
   - 2216: `("Отозвать", "согласие и удалить подписку на оповещения из облака Яндекса?")`
   - 2330: `("Удалить", "ПДн из облака ВКонтакте? Локальная база сохранится.")`
   - 2339: `("Удалить", "ПДн из облака Яндекс? Локальная база сохранится.")`

## Риски

- Все 10 вызовов должны получить `title` первым аргументом — иначе в
  заголовок попадёт старый длинный текст, а `detail` будет `undefined`
  (диалог останется работоспособным, но некрасивым). Проверить поиском
  `confirmAuto(` — не осталось одинарного вызова.
- `white-space: pre-line` не влияет на существующие тексты без `\n`.
- Emoji ✅/❌ в строках альтернатив сохранены — они связывают выбор с
  кнопками; подписи кнопок (title «Да»/«Нет») не меняются.

## Проверка

1. Удаление записи: заголовок «Удалить» по центру, ниже имя+дата.
2. Импорт базы (вставка из буфера и/или миграция): заголовок «Импорт»,
   ниже две строки — «✅ — объединить (N зап.)» и «❌ — заменить текущую
   базу», по центру; выбор работает как раньше.
3. «Сейчас»/отзыв согласия/удаление ПДн — заголовок-глагол, уточнение
   ниже; диалоги без уточнения не оставляют лишнего отступа.
4. Светлая/тёмная тема, Escape и клик по оверлею — поведение прежнее.
5. `npm run build` не запускать (AGENTS.md).

## Затрагиваемые файлы

- `LunarReturns/index.html`: +1 div в разметке, ~6 строк CSS,
  сигнатура `confirmAuto` и 10 вызовов.

# Итерация 2: при пустой базе (или только заготовка «Ада») импорт без вопроса (07.09.2026)

## Цель

Если текущая база пуста или состоит только из заготовки «Ада»
(`[{n:"Ада", d:"1815-12-10"}]`), импорт базы выполняется без диалога
«объединить/заменить» — входящие записи просто замещают текущие.

## Контекст кода

- Заготовка «Ада»: `lrSeedJson()` (index.html:953-955) возвращает ровно
  `[{n:"Ада", d:"1815-12-10"}]`; сид ставится при первом запуске
  (1187-1188, `adaSeeded=true`).
- Три пути импорта с вопросом «✅ объединить / ❌ заменить»:
  `importDbText()` ~2162 (вставка из буфера/QR),
  `vkDbGet()` ~2623 (облако ВК; там `incoming` может быть и заготовкой
  «Ада»/«Я» при пустом облаке), cloudGet→S3 ~2723 (облако Яндекса,
  аналогично).

## Изменения (только `LunarReturns/index.html`)

1. Рядом с `lrSeedJson()` добавить хелпер:
   ```js
   // База «пустая по сути»: ничего или только стартовая заготовка «Ада» —
   // спрашивать при импорте нечего, просто заменяем.
   function dbIsTrivial() {
       return db.length === 0 || JSON.stringify(db) === lrSeedJson();
   }
   ```
2. Во всех трёх местах заменить
   `const doMerge = await confirmAuto("Импорт", ...)` на
   ```js
   const doMerge = !dbIsTrivial() && await confirmAuto("Импорт",
       "✅ — объединить (" + incoming.length + " зап.)\n❌ — заменить текущую базу");
   ```
   При тривиальной базе диалог не открывается, `doMerge=false` → ветка
   «заменить» (`db = incoming`), остальной код (backup/sort/save/status)
   без изменений. Статусные сообщения («База загружена из облака…»,
   «Записей: …») остаются как есть.

## Решения и компромиссы

- «Только Ада» = точное совпадение с `lrSeedJson()` (имя + дата), а не
  «одна запись с именем Ада»: запись «Ада» с правленной пользователем
  датой уже считается осмысленной базой — вопрос показывается.
- Проверка стоит ДО диалога — при тривиальной базе он вообще не мигает;
  `adaSeeded` не трогаем (ветки замены уже ставят `adaSeeded=false` /
  пересчитывают его сами: 2168, 2629, 2729).
- Побочный эффект: импорт пустого массива `[]` в пустую базу тоже пройдёт
  без вопроса — приемлемо, результат предсказуем.

## Проверка

1. Свежая база (только «Ада») → вставка базы из буфера: диалога нет,
   база заменена, статус «Записей: N».
2. База с пользовательскими записями → вставка: диалог «Импорт» как
   раньше.
3. Облако ВК/Яндекс с пустым облаком (заготовка «Ада»/«Я») при
   тривиальной локальной базе: без вопроса; `adaSeeded` и статусные
   сообщения корректны.
4. Синтаксис скриптов; `npm run build` не запускать (AGENTS.md).
