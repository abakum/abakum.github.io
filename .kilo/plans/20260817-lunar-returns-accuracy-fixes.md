# Lunar Returns: равные фазовые вёдра + совпадение по символу

## Контекст и решение
Инвариант: у рождённого под символом X «удачные» годы — тоже годы символа X; количество «удачных» годов равно для всех фаз. Решение (выбрано пользователем): 8 равных ведёрок по 1/8 цикла, совпадение фазы = совпадение символа; критерий по расстоянию удаляется.

Файл: `LunarReturns/index.html`.

## Изменения
1. `PHASE_ICON`/`PHASE_RU` (строки ~163-164): сократить до 8 элементов (`🌑🌒🌓🌔🌕🌖🌗🌘` / `Новолуние, Молодая луна, Первая четверть, Прибывающая луна, Полнолуние, Убывающая луна, Последняя четверть, Старая луна`).
2. `phaseInt` (строки ~165-177): заменить тело на `return Math.floor(m.phase * 8) % 8;`. Удалить константы и хелперы, ставшие неиспользуемыми: `PHASE_POINT_W`, `NEW_MOON_W`, `NEW_MOON_ILLUM`, `moonIllum`.
3. `phaseMatch` (строки ~179-183): заменить на `phaseInt(a) === phaseInt(b)`; удалить `PHASE_MATCH_W`.
4. Ничего больше не трогать: зодиак, границы знаков, TZ-логика, отображение `p0` в строках матрицы — без изменений (отображение натального значка в совпавших годах уже соответствует инварианту).

## Последствия (осознанные, отметить пользователю)
- Значок натала может смениться у родившихся вблизи новых границ (например, возраст Луны 2.0 сут): 🌒 становится 🌑 (ведро 0–3.7 сут); матрица приобретёт совпадения по фазе с годами ведра 🌑 (2018 🌑♍︎; 2026 — одиночное 🌑; 2007 🌑 но Лев, одиночное до текущего возраста — скрыто).
- Подписи «Новолуние/Первая четверть/Полнолуние/Последняя четверть» обозначают 3.7-суточные срезы, а не точные моменты.
- Ожидаемая доля «удачных» по фазе лет ≈ 1/8 для любого натала — равенство по построению.
