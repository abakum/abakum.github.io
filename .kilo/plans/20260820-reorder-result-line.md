# Plan: Фиксация филлеров по протоколу калибровки (LunarReturns/index.html)

Контекст: колонки строки года `v w z p t`; эталонные ширины из протокола: `v/w/p` (эмодзи) = 22.0px, `z ♐︎` = 13.4px, `t ☽/☾` = 9.1px (последняя колонка, филлер не нужен).

## Подбор филлеров (по протоколу)

| Колонка | Цель | Лучший филлер из измеренных | Ширина | Ошибка |
|---|---|---|---|---|
| v 🐒, w 6️⃣, p 🌔 | 22.0px | `\u2003\u2004` | 21.3px | −0.7px (−3%) |
| z ♐︎ | 13.4px | `\u2002\u2004` | 13.3px | −0.1px (−0.7%) |
| t ☽/☾ | — | `""` | — | — |

Комбинации точнее 21.3 для 22.0px из измеренных единиц не составляются (шаг \u2006 = 2.7px слишком велик). Накопительный дрейф ≤0.7px × 3 колонки ≈ 2px — на глаз незаметен.

## Изменения в `LunarReturns/index.html`

1. Константы (строки ~125–127):

   ```js
   const SPACE = "\u2002\u2004";      // 13.3px — под ♐︎

   ```
   (комментарии не добавлять — заменить значения существующих констант; строки-«\u2003\u2006» и «\u2003\u2003» удалить).
2. Использование в `la()` уже корректно: `v/w/p → WIDE_SPACE`, `z → SPACE`, `t → ""` — код цикла не менять.
3. Удалить вызов `calibrateWidths()` из `renderResult()`, саму функцию `calibrateWidths()` и флаг `widthCalibrated` (калибровка была разовой).
