# Чекбокс согласия на хранение ПДн в облаке (152-ФЗ / GDPR) — LunarReturns

Файл: `LunarReturns/index.html` (единственный изменяемый файл; бэкенд не трогаем).

## Контекст

- `#status` — вводный абзац, строка ~122.
- Кнопки облака: `#loginBtn` (🔑, строка ~101), `#cloudPutBtn` (📤), `#cloudGetBtn` (📥); показываются после OAuth в `checkOAuthHash()` (~932) и скрываются в `logoutYandex()` (~943).
- Удаление облачных ПДн без изменений бэкенда: presigned PUT пустого массива `[]` в S3 перезаписывает объект пользователя. Функция `cloudPresign(action)` (~952) уже умеет выдавать PUT-URL по токену.

## Ключевое решение

Снятие галочки согласия при активной сессии Яндекса = отзыв согласия = **удаление облачных ПДн** (PUT `[]`), при этом **локальная база в localStorage полностью сохраняется**. Пользователю показывается `confirm()` перед удалением.

## Изменения

1. **HTML перед `<p id="status">`** (~строка 121):

   ```html
   <label style="display:block; font-size:0.9em; color:#555;">
     <input type="checkbox" id="pdConsent">
     Согласен(на) на хранения моих персональных данных (ПДн) и ПДн третьих лиц
     (имена и даты рождения) в Яндекс.Облаке (🔑📤) согласно 152-ФЗ и GDPR.
     Отзыв согласия удаляет ПДн из Яндекс.Облака.
   </label>
   <p id="pdLocalNote" style="display:none; font-size:0.9em; color:#555;">
     ПДн хранятся только локально в браузере на устройстве пользователя.
   </p>
   ```

2. **JS: ключ `PD_CONSENT_KEY = "lunarreturns.pdConsent"`** рядом с `DB_KEY` (~134).

3. **Функция `applyPdConsent()`**:
   - согласие есть: показать `#loginBtn`, скрыть `#pdLocalNote`; если есть `yandexToken` — показать 📤📥;
   - согласия нет: скрыть `#loginBtn`/`#cloudPutBtn`/`#cloudGetBtn`, обнулить `yandexToken`, показать `#pdLocalNote`.

4. **Функция `cloudDelete()`** — удаление облачных ПДн с сохранением локальной базы:
   - `cloudPresign("put").then(data => fetch(data.url, {method:"PUT", headers:{"Content-Type":"application/json"}, body:"[]"}))`;
   - успех: `status("Согласие отозвано: ПДн удалены из облака. Локальная база сохранена")`;
   - ошибка сети/функции: `status(..., true)` с текстом, что данные в облаке могли сохраниться, и советом повторить (поставить и снова снять галочку).

5. **Обработчик `change` чекбокса**:
   - установка: `localStorage.setItem(PD_CONSENT_KEY, "1")`, `applyPdConsent()`;
   - снятие: `localStorage.removeItem(PD_CONSENT_KEY)`;
     - если `yandexToken` есть: `confirm("Удалить ПДн из Яндекс.Облака? Локальная база сохранится.")` → OK: `cloudDelete()` → затем `applyPdConsent()` (кнопки скрыть сразу, не дожидаясь ответа сети; logout-логику выполнить, токен обнулить после запуска запроса, захватив его заранее);
     - Отмена confirm: вернуть галочку (чекбокс обратно в checked), ничего не менять;
     - если токена нет: просто `applyPdConsent()`.

6. **Интеграция**:
   - `checkOAuthHash()`: перед показом 📤📥 проверить согласие; без него токен не сохранять и выйти (защита от возврат OAuth-редиректа при снятой галочке).
   - `loginYandex()`: guard — без согласия `status("Для облачного хранения требуется согласие", true)`.
   - `logoutYandex()` не трогать `#loginBtn`, если согласия нет (кнопка остаётся скрытой).
   - Конец скрипта (~1040): инициализировать чекбокс из localStorage, вызвать `applyPdConsent()` до `checkOAuthHash()`.

## Поведение

- Новый пользователь: галочки нет, 🔑 скрыт, видна заметка «ПДн хранятся только локально…», локальная база работает.
- Галочка поставлена: 🔑 виден, штатный OAuth-поток.
- Галочка снята без входа: кнопки скрыты, ничего не удаляется (в облаке и так ничего нет).
- Галочка снята после входа: confirm → облако перезаписано `[]`, 📤📥🔑 скрыты, локальная база и токен сброшены.
- Отмена confirm: состояние не меняется.

## Валидация

- Открыть страницу: 🔑 скрыт, заметка видна, добавление/удаление записей работает.
- Поставить галочку, перезагрузить: 🔑 виден, заметка скрыта, состояние сохранилось.
- Войти (🔑), снять галочку, подтвердить: статус об удалении, кнопки скрыты, локальная база на месте.
- Поставить галочку снова, 📤, снять галочку, подтвердить, снова 🔑📥: база в облаке пуста (0 записей / «в облаке пусто» не появляется, т.к. `[]` валиден).
- Снять галочку без входа: просто скрываются элементы, confirm не показывается.
