# Lunar Returns: сортировка базы, нейтральная кнопка, Enter

Файл: `LunarReturns/index.html`.

## Изменения

1. **Сортировка по дате рождения (молодые внизу)**
   - Хелпер: `const sortDb = () => db.sort((a, b) => a.d.localeCompare(b.d) || ((a.h ?? 12) - (b.h ?? 12)) || ((a.m ?? 0) - (b.m ?? 0)));` (ISO-даты сравниваются строково; тай-брейк по времени).
   - Вызвать `sortDb()` после успешного `saveDb()` в `submitRecord()` (ветки добавления и редактирования) — при редактировании дата может измениться, порядок пересчитывается.
   - Перед сортировкой запомнить выбранный объект `const sel = selectedIdx >= 0 ? db[selectedIdx] : null;`, после — `selectedIdx = sel ? db.indexOf(sel) : -1;` (identity, не индекс).
   - `editingIdx` трогать не нужно: после сохранения вызывается `cancelEdit()` (ставит −1).
   - Для консистентности сортировать также в `pasteDb()` и `cloudGet()` после объединения (перед `saveDb()`).

2. **Убрать красный у кнопок ➕/💾**
   - Удалить CSS-правила `button.primary` и `button.primary:hover` (строки ~34–35).
   - Убрать `class="primary"` у `#addBtn` (строка ~79). Кнопка станет стандартной серой, как остальные.

3. **Enter добавляет/сохраняет**
   - Обернуть поля ввода `#fName`, `#fDate`, `#fCity`, `#fHour`, `#fMin` и `#addBtn` в `<form id="recForm" onsubmit="submitRecord(); return false;">` (существующая разметка btnrow сохраняется внутри).
   - Enter в любом поле вызовет `submitRecord()`; `return false` предотвращает перезагрузку страницы.
   - `onclick` кнопки оставить (клик мышью работает как раньше; внутри формы `type="button"` НЕ ставить, submit-кнопка и так триггерит форму — можно даже убрать onclick, но оставить для простоты не вредно: двойной вызов исключён, т.к. onclick кнопкиsubmit не вызывает form submit повторно). Решение: убрать `onclick` у кнопки, положиться на submit формы.

## Проверка

- Добавить записи с датами вразнобой — список остаётся отсортированным по `d` по возрастанию.
- Редактировать запись, сменив дату на более позднюю — она переезжает вниз; выбранная запись (`selectedIdx`) не «подменяется» (результат справа остаётся тем же человеком).
- Enter в поле имени/даты/часа/минут добавляет запись без перезагрузки; в режиме редактирования — сохраняет.
- Кнопка ➕/💾 серая, как 📋/⛶.
- `pasteDb`/`cloudGet` с объединением — итог отсортирован.
- `node --check` извлечённого скрипта; ручная проверка в браузере.

## Вне области

- Логика расчётов, QR, облако — без изменений.
