# VK-бот юбилеев: кнопки «/», религиозные дни, удаление по 👎

## Контекст
Работающий бот `~/src/LunarReturns/lunarreturns.js` (см. закрытый план
`20260925-lunarreturns-vk-bot.md`): Long Poll, триггеры «Имя ГГГГММДД
[ЧЧ:ММ] [(пояс)]», ответы реплаем, база `db.json` (ключ пир+имя+дата),
`dailyCheck()` в 09:00 МСК (годовые юбилеи), catchUp по истории.
Порт астрономии из `LunarReturns/index.html` уже в боте (ASTRO-секция:
`moonNew`, `lunarNewsFulls` — ещё НЕ перенесена, титхи/зодиаки — есть).

## Решения (согласованы с пользователем)
- Оповещения о религиозных днях — в 09:00 МСК, только если сегодня есть дни
  включённой религии; иначе молчание.
- 👎 на ответ бота удаляет **только ту запись**, чей ответ был дизлайкнут
  (запись определяется по тексту ответа: имя + дата из заголовка).
- Кнопки по «/» — только в личном чате (peer_id < 2000000000).
- Тап на религиозную кнопку: переключает флаг, отправляет **все дни этой
  религии на год вперёд** (от сегодня, МСК) и полную клавиатуру. Состояние
  кнопки — эмодзи-пара без текста: включено `[☦️🔔]`, выключено `[☦️🔕]`
  (аналогично ☪️ ☸️ ✝️ ✡️); тап переключает и перерисовывает клавиатуру.

## Поведение
1. **Триггер «/»** (reply на «/», личный чат): ответ-сообщение с inline
   клавиатурой: `🗑` + по паре на религию: `[☦️🔔]/[☦️🔕]`, `[☪️🔔]/[☪️🔕]`,
   `[☸️🔔]/[☸️🔕]`, `[✝️🔔]/[✝️🔕]`, `[✡️🔔]/[✡️🔕]` (payload: `del`,
   `rel:orth`, `rel:islam`, `rel:bud`, `rel:cath`, `rel:jud`, цвет
   secondary). 🔔 = оповещения включены, 🔕 = выключены. В групповом чате
   на «/» не отвечать.
2. **Кнопки** (событие LP `message_event`, нужна галка «Действие с
   сообщением»):
   - **Религиозная** → toggle флага в `db.settings[peerId]` + НОВОЕ сообщение:
     «{Название}, год вперёд:» + список «ДД.ММ — название» (по строке) +
     полная клавиатура с новым состоянием пар. Снекбар не нужен.
   - **🗑 (первый тап)** → НОВОЕ сообщение-подтверждение: список всех записей
     чата («Имя ДД.ММ.ГГГГ [ЧЧ:ММ]», по строке) + inline клавиатура из двух
     кнопок: `🗑` (payload `del:yes`, negative) и `❌` (payload `del:no`,
     secondary). Если записей нет — снекбар «записей нет», клавиатура не меняется.
   - **🗑 (подтверждение, `del:yes`)** → удалить все записи чата
     (`db.records = records.filter(r => r.peerId !== peerId)`) + снекбар
     «удалено записей: N» (`messages.sendMessageEventAnswer` + `showSnackbar`,
     как `answerEvent` в pinguin/vk.go:133) + полная клавиатура.
   - **❌ (`del:no`)** → снекбар «отменено» + полная клавиатура (ничего не удалять).
3. **Настройки**: `db.settings = { [peerId]: { orth, islam, bud, cath, jud } }`,
   по умолчанию все выключены; `loadDb` уже толерантен к новым полям.
4. **Дайджест**: в `dailyCheck()` (09:00 МСК) после юбилеев собрать сегодняшние
   (МСК) дни по включённым религиям чата; отправить отдельным сообщением,
   формат «{Название}: {дни через запятую}»; если пусто — молчать.
5. **👎**: событие LP `message_reaction_event` (галка «Действие с реакциями на
   сообщение»; точное имя типа проверить логом `LOG_UPDATES=1`). Если 👎 от
   человека (`from_id > 0`) на сообщение бота:
   `messages.getByConversationMessageID(peer, cmid)` → текст → из первой
   строки «Имя ГГГГ-ММ-ДД …» взять имя и дату → удалить запись с этим
   пиром+именем+датой. Идёмпотентно: нет записи — молча.

## Порт из `LunarReturns/index.html` (чистый JS; блок RELIG в боте)
- Пасха: гауссова `easterJdn` (~1700–1742), `gregToJdn`/`jdnToGreg`.
- `lunarNewsFulls` (1768) — ислам, буддизм.
- Иудейские: `hebrewLeap`, `hebrewRoshJdn`, `jdnToHebrew`, `HEB_HOL`,

- Христианские: `ORTH_OFFS`, `CATH_OFFS`, `ORTH_FIXED`, `CATH_FIXED`,
  `buildChristianDays` (1798–1823).
- Ислам: `ISLAM_HOL`, `ISLAM_ANCHOR_JDN`, `buildIslamic` (1825–1842).
- Буддийские: `BURYAT_MS`, `moonPhaseAt`, `dawnMs`, `dawnLunarDay`,
  `nmTimeMs`, `nmDayLabel`, `dayWithTithi`, `buildBuddhist` (1857–1930).
- Обобщение: в приложении `dayStart/dayEnd` — глобальные (двое суток МСК);
  в боте сделать их **параметрами** `build*(dayStart, dayEnd)`:
  - дайджест: сутки МСК (сегодня);
  - «год вперёд»: от сегодняшнего jdn до +366; `buildBuddhist` построить
    по затронутым годам и отфильтровать.
- Формат «год вперёд»: «ДД.ММ — название», по строке, по возрастанию даты.

## Задачи
1. RELIG-блок: перенос функций; `religiousDigest(settings)` (сегодня) и
   `religiousYear(rel)` (год вперёд).
2. `db.settings`, `getSettings(peer)`, `toggleRel(peer, key)`.
3. `messagesSend`: параметр `keyboard` (inline, payload-строки);
   `relKeyboard(settings)` — кнопка 🗑 + пары `[emoji 🔔|🔕]` по состоянию
   настроек.
4. Триггер «/» в `handleMessage` (только личный чат) → клавиатура.
5. `longPollStep`: `message_event`:
   - `rel:*` → toggle + «год вперёд» + клавиатура;
   - `del` (первый тап 🗑) → подтверждение со списком записей чата +
     кнопки `🗑`/`❌`;
   - `del:yes` → удаление + снекбар + полная клавиатура;
   - `del:no` → снекбар «отменено» + полная клавиатура;
   реакция 👎 → удаление записи.
6. `dailyCheck`: дайджест отдельным сообщением.
7. README: раздел про кнопки/религии/👎 (+ включить события «Действие с
   сообщением» и «Действие с реакциями на сообщение» в Long Poll).
8. `test`-режим: `test rel` — сегодняшний дайджест всех религий;
   `test rel:orth` — православные дни на год вперёд.

## Риски
- Имя события реакций в LP — проверить `LOG_UPDATES=1`, поставив реакцию;
  поправить фильтр при другом имени.
- Кнопки без текста: проверить читаемость пар `[☦️🔔]/[☦️🔕]` в клиентах ВК;
  фолбэк — добавить короткое слово («☦️🔔 Православные»).
- `buildBuddhist` — объёмный перенос, сверить с приложением (Сагаалган и др.).
- Событие `message_event` не приходит, если в сообществе не включена галка —
  задокументировать в README.

## Валидация
- `node lunarreturns.js test rel` — сегодняшний дайджест всех 5 религий,
  сверить со страницей приложения (включая пасхальные offsets и фиксированные).
- `node lunarreturns.js test rel:orth` — православные дни на год вперёд
  (Пасха, Вход в Иерусалим, Радоница и т.д.) — сверить с приложением.
- Личный чат: «/» → клавиатура с парами `[…🔕]`; тап ☦️ → список года вперёд
  + клавиатура с `[☦️🔔]`; повторный тап → снова `[☦️🔕]`; `db.settings`
  меняется.
- 🗑: первый тап → список записей чата + `🗑`/`❌`; `❌` → ничего не удалено;
  `🗑` → записи чата удалены (db.json), записи других чатов не тронуты;
  при пустом чате — снекбар «записей нет».
- 09:00 МСК (или трюк с датой записи = сегодня): дайджест приходит только
  при наличии дней включённых религий.
- 👎 на ответ: исчезает ровно одна запись; остальные остаются.
- Повторный запуск `lunarreturns-install.sh` не трогает `db.json` в /var/lib.
