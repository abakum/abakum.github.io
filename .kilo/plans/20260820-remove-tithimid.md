# LunarReturns: улучшения index.html (пункты 1–6)

## 1. Удалить tithiMid (мёртвый код)
`tithiMid` (строки 184–212) начинается с безусловного `return t;`. Единственный вызов — в `la()`.

- Удалить функцию `tithiMid` целиком.
- В `la()`: `const mMid = moonNew(birth);` вместо `tithiMid(...)` + `moonNew(tMid)`.
- В цикле `la()`: `moonNew(addYears(birth, i))` вместо `addYears(tMid, i)`.

## 2. Прокрутка к результату при тапе на запись
- В `selectRecord` после показа `#resultSec` добавить:
  `resultSec.scrollIntoView({ behavior: "smooth", block: "start" });`

## 3. Аннотация на месте статуса, показ при первой загрузке
- Удалить четыре `<p>` после `<h1>` (строки 67–70).
- При init вывести аннотацию через `status(...)` (текст четырёх абзацев, объединённый). Статусные сообщения заменяют аннотацию до перезагрузки.

## 4. Тап на запись = заполнение формы, убрать ✏️
- В `renderList()` удалить кнопку `edit` (строки 368–371); `row.onclick` вместо `selectRecord(i)` вызывает `selectRecord(i); startEdit(i);` (прокрутка к результату из п.2 сохраняется).
- `startEdit` остаётся: заполняет имя/дату/час/минуты и меняет кнопку формы на 💾 («Сохранить»). Без ✏️ это единственный вход в режим правки.

## 5. Тап на 💾 сохраняет и очищает имя/дату
- Текущее поведение `submitRecord` уже очищает `fName`/`fDate`/`fCity` (строки 441–443); дозачищать `fHour`/`fMin` через `cancelEdit()` (она уже вызывается после сохранения и чистит все поля). Проверить, что после сохранения кнопка возвращается к ➕.

## 6. Кнопка удаления рядом с 💾, убрать ❌ из строк
- В `renderList()` удалить кнопку `del` (строки 372–375).
- В форму рядом с `addBtn` (после неё, строка 80) добавить `<button type="button" id="delBtn" onclick="deleteCurrent()" title="Удалить">➖</button>`.
- Новая функция `deleteCurrent()`:
  - `const i = editingIdx >= 0 ? editingIdx : selectedIdx; if (i < 0) { status("Сначала выберите запись", true); return; }`
  - Вызвать существующий `removeRecord(i)` (confirm внутри уже есть).
  - После удаления `cancelEdit()` уже вызывается из `removeRecord` при `editingIdx === i` — иначе вызвать вручную, чтобы форма очистилась.
- В `startEdit` кнопка 💾 остаётся; `delBtn` активна всегда.
