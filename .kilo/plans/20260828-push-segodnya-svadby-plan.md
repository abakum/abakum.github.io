# Push «Сегодня»: возраст для ДР и годовщины свадеб

## Контекст

`LunarReturns/sw.js`, обработчик `push` (строки 61–76): читает из IndexedDB ключи `"db"` (`[{n, d:"YYYY-MM-DD"}]`) и `"days"` (`[{n, d:"MM-DD"}]`), отбирает записи с совпадением `MM-DD` по московской дате (29.02 ↔ 28.02 в невисокосный год) и показывает `showNotification(заголовок, {body: имена через ", ", tag:"bd"})`. Бэкенд и подписка не меняются — облако получает только `MM-DD` (`allPushDates()`), вся новая логика на устройстве.

## Решения

1. **Заголовок** — всегда `"Сегодня"` (вместо «День рождения»/«События»/«День рождения и события»).
2. **Тело** — элементы через `", "` как сейчас; каждый элемент формируется так:
   - **ДР** (имя без `+`, запись из `db`): `Иван 17` — имя + число исполняемых лет (`год МСК − год из d`).
   - **Свадьба** (имя содержит `+`, запись из `db`): `Иван+Мария 17 розовая` — имя + число лет + прилагательное строчными буквами; год не из таблицы → `Иван+Мария 27` (только число).
   - **События** (`days`, года нет): только имя, без числа.
   - Число лет < 1 (дата будущего/текущего года) → без числа, просто имя.
3. **Таблица годовщин** (полная 1–80, прилагательные согласованы с «свадьба», строчные):
   1 ситцевая, 2 бумажная, 3 кожаная, 4 льняная, 5 деревянная, 6 чугунная, 7 медная, 8 жестяная, 9 фаянсовая, 10 оловянная, 11 стальная, 12 никелевая, 13 кружевная, 14 агатовая, 15 стеклянная, 16 бирюзовая, 17 розовая, 18 гранатовая, 19 криптоновая, 20 фарфоровая, 21 опаловая, 22 бронзовая, 23 берилловая, 24 сатиновая, 25 серебряная, 30 жемчужная, 35 полотняная, 40 рубиновая, 45 сапфировая, 50 золотая, 55 изумрудная, 60 бриллиантовая, 65 железная, 70 благодатная, 75 корональная, 80 дубовая.
4. Совпадений нет / базы пусты → тихо завершиться (как сейчас).

## Изменения (только `LunarReturns/sw.js`)

1. Добавить `const WED = {1:"ситцевая", …, 80:"дубовая"}` (таблица выше) и хелпер `yearsOf(d)`: `год МСК (todayMsk().slice(0,4)) − Number(d.slice(0,4))`, при результате `< 1` вернуть `null`.
2. Переделать `birthdayNames(list)` → `dbLabels(list)`: тот же отбор по `MM-DD`, но вместо голого имени вернуть строку-элемент:
   - `const y = yearsOf(r.d)`; если `y === null` → `r.n`;
   - `r.n.includes("+")` → `` `${r.n} ${y}${WED[y] ? " " + WED[y] : ""}` ``;
   - иначе → `` `${r.n} ${y}` ``.
3. `dayNames` оставить как есть (только имена).
4. В `push`: `title = "Сегодня"`, `body = labels.concat(days).join(", ")`, `tag: "bd"` без изменений; пусто → `return`.
5. Бампнуть `CACHE` с `lunarreturns-v3` на `lunarreturns-v4`, чтобы установленные PWA обновили SW.

Вне области: UI (список, текст результата, QR), бэкенд/подписка, символика имени с `+` где-либо кроме пуша.

## Проверка

1. `npx serve LunarReturns`, открыть страницу, DevTools → Application → Service Workers → обновить, убедиться, что активировался новый SW (v4).
2. В DevTools → Application → IndexedDB → `lunarreturns` → `kv`: положить `"db"` = `[{"n":"Иван","d":"<текущий год−17>-<сегодня MM-DD>"},{"n":"Иван+Мария","d":"<год − 17 лет сегодня>"},{"n":"Старые","d":"<год − 27 лет сегодня>"}]` (тексты по сегодня МСК), `"days"` пуст.
3. Application → Service Workers → кнопка «Push»: ожидание уведомления «Сегодня» с телом `Иван 17, Иван+Мария 17 розовая, Старые 27`.
4. Крайние случаи: запись с датой текущего года (без числа), `"db"` отсутствует, но `"days"` с сегодняшней `MM-DD` (только имя), пустые ключи (нет уведомления).
