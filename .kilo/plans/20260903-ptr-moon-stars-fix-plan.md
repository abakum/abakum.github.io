# План: фикс месяца и звёзд на небе при PTR (выделено из cloud-busy-guard)

**Дата:** 2026-09-03
**Файлы:** `LunarReturns/index.html`
**Статус:** Дополнение B (месяц/звёзды, рев. 3) реализовано и закоммичено (`8c1fe37`), но на устройстве два дефекта — фиксируется здесь. Тактильный отклик PTR — отдельный реализованный план (`20260903-ptr-taptic-plan.md`, `05d3e58`).

## Дефекты с устройства

1. **Месяц — битая картинка:** `#ptrMoon` использует `icons/icon-192.png`, которого нет на VK-хостинге (деплой из `build/`, а `scripts/copy-build.js` не включает `icons/`; туда же не входят sw.js/manifest — SW на VK не работает, его тихий сбой нерелевантен) → 404.
2. **Месяц/звёзды под заголовком, едут с формой:** PTR вешает `transform: translateY()` на `body`. Трансформированный предок = containing block для fixed-потомков и stacking context: `#ptrMoon`/`#ptrStars` (дети body) отрываются от вьюпорта и красятся внутри контекста body ПОСЛЕ его фона → видны поверх формы и перемещаются вместе с ней.

## Изменения

1. **HTML (index.html):** в `#ptrMoon` заменить `src="icons/icon-192.png"` → `src="1f319.webp"`, `width="48" height="48"` → `width="24" height="24"` (ассет уже деплоится на VK — тот же месяц, что в заголовке). После `<body>` оставить `#ptrMoon`/`#ptrStars` как есть, а весь остальной контент (от `<h1 id="titleH1">` до последнего элемента перед `</body>`) обернуть в `<div id="ptrWrap">`.

2. **CSS:** из правила `body` убрать `max-width/margin/padding/background/color`, оставив `font-family`; добавить:

```css
#ptrWrap {
    max-width: 640px;
    margin: 0 auto;
    padding: 12px;
    background: var(--bg);
    color: var(--text);
}
```

В правиле `#ptrMoon` поменять `width: 48px; height: 48px;` → `width: 24px; height: 24px;`.

3. **JS, PTR-IIFE:** в начале взять `const ptrBody = document.getElementById("ptrWrap");` и заменить все три обращения `document.body.style.transform/transition` (в `ptrReset`, `touchmove`, `ptrEnd`) на `ptrBody.style...`. Обращения к `document.documentElement.classList...` не трогать.

4. Сборка/SW — без изменений (icons на VK не нужны: SW туда не деплоится; на прямом веб-хостинге icons существуют, install v10 проходит).

## Почему это работает

`#ptrWrap` — обычный in-flow блок в корневом stacking context: `#ptrMoon`/`#ptrStars` с `position: fixed; z-index: -1` красятся до его фона → спрятаны за формой, но над небом `html`; containing block — вьюпорт (трансформации на body/html больше нет). Сдвиг `#ptrWrap` при PTR на них не влияет — они остаются на небе, обёртка раскрывает их сверху.

## Валидация

1. VK-клиент, светлая тема: тяга — 🌙 заголовка гаснет, на небе сверху слева плавно проявляется маленький месяц (1f319.webp, не битый), форма едет под ним; к порогу непрозрачен.
2. Тёмная тема: месяц виден сразу, звёзды проявляются по мере тяги — оба на небе, не поверх формы.
3. Отпускание до порога — контент защёлкнулся, небо закрылось; заголовочный 🌙 вернулся. Тяга за порог — толчок, reload.
4. Десктоп, узкое окно (≤ ~664px): колонка заполняет ширину, небо закрыто — вид идентичен прежнему.
5. Десктоп, широкое окно: боковое небо-градиент как раньше; месяц не виден ни при какой ширине (горизонталь привязана к колонке: `calc(50% - 320px + 24px)` = внутри колонки, за фоном обёртки); звёзды всегда `opacity: 0` (ставит только `ptrSky()` из VK-touch-PTR); заголовочный 🌙 на месте.
6. Прямой веб-хостинг: SW и иконки работают как раньше.
