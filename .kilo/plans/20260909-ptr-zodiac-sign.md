# Исправить знак на небе PTR: рисуется «лев», а Луна в «деве»

## Симптом (репорт 2026-09-09 23:23 МСК)

Текст «Сейчас…» (`renderNow()`) показывает Луну в деве (`♍︎#дева_`),
а фигурка-созвездие на небе PTR подписана «лев».

## Причина

`moonNew(date)` (`LunarReturns/index.html:1001`) ждёт дату **по МСК (UTC+3)**:
`jde = (getTime() − TZ_MS)/86400000 + 2440587.5`, где `TZ_MS = 3ч` (строка 639).

- `renderNow()` (строка 1579) передаёт `new Date(Date.now() + TZ_MS)` — верный
  момент → в легенде «дева» (верно).
- `drawZodiac()` (строка 841) передаёт сырой `new Date()` → jde уходит на
  **3 часа в прошлое** → фигурка и подпись считаются по положению Луны 3 часа
  назад («лев»). Луна проходит ~0.55°/ч; 3 ч ≈ 1.65° — если граница Лев/Дева
  (150°) пройдена в эти 3 часа, знаки расходятся. Ровно этот случай.
- Та же латентная ошибка в строке 1056: юникод-луна неба `#ptrMoon` (🌘)
  считается по `moonNew(new Date())` — тоже на 3 часа раньше.

Все остальные вызовы `moonNew` соглашению следуют (легенда/`la` через
МСК-даты, строка 1653 — полдень МСК, `moonPhaseAt` строка 1734 сам добавляет
`TZ_MS`). Выбиваются только строки 841 и 1056.

## Изменения

Всё в `LunarReturns/index.html`:

1. **Строка 841** (`drawZodiac`):
   ```js
   const fig = ZODIAC_FIGS[Math.floor(moonNew(new Date(Date.now() + TZ_MS)).longitude / 30) % 12];
   ```
2. **Строка 1056** (`#ptrMoon`):
   ```js
   if (ptrMoonBox) ptrMoonBox.textContent = phaseName(tithiInt(moonNew(new Date(Date.now() + TZ_MS))), false);
   ```
3. **Комментарий** к `drawZodiac` (строки 820–822) дополнить: дата для
   `moonNew` — МСК (`Date.now() + TZ_MS`), как в `renderNow()`; инлайновый
   расчёт индекса знака сохранить — нельзя заменить на `moonZodiacInt`/`norm360`:
   путь `?ptr=N` (строка 869) исполняется до объявления этих const (строки
   1058–1062), TDZ.
4. **`LunarReturns/sw.js` строка 1**: `CACHE = "lunarreturns-v13"` (конвенция
   репо: каждое изменение приложения = бамп версии кэша).

## Не делать

- Не рефакторить `moonNew` на true-UTC — затронет все вызовы, риск неоправдан.
- Не менять одноразовость отрисовки (`zodiacDrawn`) — знак в пределах суток
  практически не меняется.
- Не запускать `npm run build` (запрещено AGENTS.md; сборка в CI при деплое).

   (`♍︎#дева_`, `🌘#старая_луна`).
3. Эфемеридная сверка: вечером 2026-09-09 эклиптическая долгота Луны
   ≈ 150–152° → Дева; фигурка и подпись — «дева».
