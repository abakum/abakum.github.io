# Карточка «Сейчас» в textarea при старте страницы

## Контекст

`LunarReturns/index.html`: секция `#resultSec` с `#resultText` при старте скрыта (`display:none` в HTML) и показывается только `renderResult()` при выборе записи (строки 621–641). `la(birth)` (строки 321–365) первым элементом массива `years` возвращает «легенду» — 7 строк (солнечный знак, восточный год, день недели, лунный знак, фаза, титхи, хештег-строка), а дальше цикл добавляет будущие юбилейные годы.

Требование: при старте страницы textarea видна, первая строка — «Сейчас <дата и время сейчас>», дальше — легенда текущего момента, без будущих дат.

## Решения

1. **«Легенда»** — тот же блок, что первый элемент `la()` (строки 321–342: `mMid`…хештег-строка), вычисленный для текущего момента; без цикла будущих лет.
2. **Дата/время** — по московскому времени (конвенция приложения, `TZ_MS`), формат: `Сейчас 2026-08-30 Воскресенье 22:28` (дата, имя дня недели из `wdLocale`, время `HH:MM`).
3. **Время жизни карточки** — только при старте: `renderResult()` при выборе записи перезаписывает её как сейчас; после `hideResult()` (удаление/очистка/режим религий) карточка не восстанавливается.
4. **QR** под текстом — как в `renderResult()`, кодирует текст карточки.
5. **Высота textarea** — по числу строк, всё содержимое видно (без «сжатия» минус строка, как в сжатом режиме `renderResult`).

## Изменения (только `LunarReturns/index.html`)

1. Вынести блок легенды из `la()` в отдельную `function legend(t)` (возвращает строку из 7 строк; `const f = new Date()...` остаётся в `la` — легенде не нужен); `la(birth)` начинается с `const years = [legend(birth)]`.
2. Добавить `function renderNow()` по образцу `renderResult()` (строки 630–640):
   - `const now = new Date(Date.now() + TZ_MS)` — UTC-геттеры дают МСК; передача в `legend(now)` корректна, т.к. `moonNew` сам вычитает `TZ_MS` (тот же приём, что в `moonPhaseAt`);
   - `when = "Сейчас " + YYYY-MM-DD + " " + WD_RU-имя + " " + HH:MM`;
   - `text = when + "\n" + legend(now)`;
   - `ta.value = text`, показ `#resultSec`, `ta.rows = text.split("\n").length`, высота auto, `showQr(resultQr, text)`.
3. В стартовом блоке после `renderList()` (строка ~1485) вызвать `renderNow()`.
4. Бампнуть `CACHE` в `sw.js` с `lunarreturns-v5` на `lunarreturns-v6` (index.html в прекеше; навигация network-first, но бамп — принятая в репо практика).

Вне области: обновление карточки по таймеру при открытой странице, восстановление карточки после `hideResult()`, режим религий, бэкенд/пуши.

## Проверка

1. `npx serve .`, открыть `http://localhost:3000/LunarReturns/`: textarea видна сразу; первая строка «Сейчас <сегодня МСК> <день недели> <ЧЧ:ММ>», дальше 7 строк легенды; будущих годов нет; QR соответствует тексту.
2. Выбрать запись — вывод как раньше (легенда + будущие годы), карточка заменяется; кнопка ⋯/⋮ и ⎘ работают.
3. Регрессия рефакторинга: легенда в выводе `la()` для любой записи побайтно совпадает с прежней (первая строка имени-заголовка не тронута).
4. Установленное PWA: после деплоя и обновления SW (v6) страница при старте показывает карточку.
