# VK: при пустом облаке подставлять «Я <мой ДР>» как в Яндексе

## Контекст

- Яндекс-поток (`cloudGet`, `LunarReturns/index.html:1549-1555`): при 404 из S3 сервер отдаёт `data.birthday` (YYYY-MM-DD), приложение сеет `{n:"Я", d: birthday}`; если ДР нет — заготовка `Ада` + `adaSeeded = true`.
- VK-поток (`vkDbGet`, `LunarReturns/index.html:1465-1506`): при пустом хранилище ВСЕГДА сеет `Ада` (строка 1484) и ставит `adaSeeded = true` (строка 1494), сообщение «В облаке ВКонтакте пусто — заготовка: Ада» (строка 1501).
- ДР профиля ВК доступен через `vkBridge.send("VKWebAppGetUserInfo")` → поле `bdate` в формате `"DD.MM.YYYY"`; при скрытом годе — `"DD.MM"`.

## Изменения (только `LunarReturns/index.html`, функция `vkDbGet`)

1. При `empty` запросить профиль: `await vkBridge.send("VKWebAppGetUserInfo")` (внутри общего try/catch; ошибка → fallback на `Ада`).
2. Распарсить `bdate` двумя шаблонами:
   - полный `^(\d{2})\.(\d{2})\.(\d{4})$` → `d = YYYY-MM-DD`;
   - без года `^(\d{2})\.(\d{2})$` → год берём от Ады: `d = "1815-" + MM + "-" + DD`.
3. Если `d` получен (в т.ч. с годом 1815) — `incoming = [{ n: "Я", d }]`, `adaSeeded = false`; если `bdate` отсутствует/нераспознан — как сейчас `Ада` (`1815-12-10`), `adaSeeded = true`.
4. Сообщения зеркально Яндекс-потоку (строки 1578-1582):
   - с полным ДР: «В облаке ВКонтакте пусто — загружена дата рождения из профиля ВКонтакте»
   - ДР без года: «В облаке ВКонтакте пусто — дата рождения из профиля без года, подставлен 1815»
   - без ДР: «В облаке ВКонтакте пусто и дата рождения в профиле не указана — заготовка: Ада»

## Не менять

- Логику `adaSeeded` в остальном приложении (строки 414, 518, 562 и т.д.).
- `vkDbPut`, `vkDbClear`, Яндекс-поток.

## Граничные случаи

- `bdate` без года (`"DD.MM"`) → «Я» с `1815-MM-DD`, `adaSeeded = false`.
- `bdate` скрыт полностью / `GetUserInfo` отклонён → `Ада` (как сейчас), `adaSeeded = true`.
- `bdate` есть, но облако не пусто → профиль не запрашивать (запрос только в ветке `empty`).

## Валидация

1. Локально открыть `LunarReturns/index.html?vk_app_id=1` (vkBridge может отсутствовать — проверить, что fallback не падает).
2. В тестовом мини-аппе ВК (workflow `deploy-lunarreturns-vk-test.yml`): пустое хранилище + полный ДР → «Я <ДР>»; ДР без года → «Я 1815-MM-DD»; скрытый ДР → «Ада».
3. Повторная загрузка после сохранения базы — обычный путь без изменений.
