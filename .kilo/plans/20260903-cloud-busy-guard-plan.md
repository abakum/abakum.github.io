# План: блокировка облачных кнопок на время обмена (VK + Яндекс) — РЕАЛИЗОВАНО

**Дата:** 2026-09-03
**Статус:** Реализовано и закоммичено (`2220fc7`), включая упрощение спиннера (Дополнение A). PTR-тематика (месяц/звёзды/небо) выделена в `20260903-ptr-moon-stars-fix-plan.md`; тактильный отклик PTR — в `20260903-ptr-taptic-plan.md`.

## Контекст

Облачный обмен асинхронен и долог: `vkDbPut` пишет записи в `VKWebAppStorageSet` последовательными await, `vkDbGet` читает 990 ключей; в Яндекс-режиме те же кнопки 📤/📥 идут через presign + fetch. Тапы по 📤/📥 во время незавершённой операции интерливят запросы (чтение полузаписанной базы, двойной PUT). Отзыв согласия (`vkDbClear`/`cloudDelete`) тоже пишет в облако и участвует в той же гонке.

## Решение (как реализовано)

- `cloudBusy`/`cloudLock(on, spinBtn)`/`cloudRun(op, spinBtn)`: disable у 📤/📥 и чекбокса согласия на время обмена; снятие в `finally` на любом исходе.
- Нажатая кнопка крутится целиком со своей иконкой (`busy-spin`), метка не меняется (правка по фидбэку — Дополнение A).
- `cloudPut(btn)`/`cloudGet(btn)` целиком под `cloudRun` (VK-ветки с `await`); отзыв согласия — `cloudRun(() => vkDbClear())` / `cloudRun(() => cloudDelete(token))` без спиннера.
- Повторный тап при обмене игнорируется со статусом «Дождитесь завершения обмена с облаком».

## Валидация

1. VK: тап 📤 — кнопка крутится, 📥 и чекбокс серые; по завершении иконка восстановлена, кнопки активны; двойной быстрый тап — второй игнорируется.
2. Яндекс-режим: то же для presign/fetch-пути.
3. Попытка снять галочку согласия во время обмена — чекбокс серый и не реагирует; после завершения отзыв проходит штатно.
4. Ошибки сети (авиарежим): finally снимает блокировку, кнопки снова активны.
