# План: кнопки 🔝 и 🔙 в панели результата (LunarReturns, 07.09.2026)

## Цель

В `#resultSec .btnrow` заменить иконку возврата к строке источника на
эмодзи 🔙, добавить перед ней кнопку 🔝 (прокрутка страницы наверх).
В двухколоночном режиме кнопку 🔙 не показывать вовсе.

## Контекст кода

- Разметка: `LunarReturns/index.html:529-534`, кнопка возврата —
  `<button id="srcBtn" onclick="scrollToSourceRow()" ...>⬉</button>`.
- Показ: `renderResult()` ставит `srcBtn.style.display = ""`
  (index.html:1517); скрытие при «Сейчас»: `renderNow()` ставит `none`
  (index.html:1560). Скролл к строке: `scrollToSourceRow()`
  (index.html:1542-1545).
- Двухколоночный режим: класс `.two-col` на `#ptrWrap` ставит
  `setTwoCol()` (index.html:558-564); результат там выравнивается
  напротив строки-источника (`alignResultToRow`, index.html:1460), так
  что 🔙 в этом режиме лишняя.

## Изменения (только `LunarReturns/index.html`)

1. **Разметка** (btnrow, index.html:529-534):
   - перед `#srcBtn` добавить
     `<button type="button" id="topBtn" onclick="window.scrollTo({top:0,behavior:'smooth'})" title="Наверх">🔝</button>`;
   - у `#srcBtn` заменить `⬉` на `🔙` (атрибуты не менять).
2. **Скрытие 🔙 в двух колонках** — CSS-правило рядом с блоком
   `.two-col` (index.html:~400-410):
   `#ptrWrap.two-col #srcBtn { display: none; }`.
   Работает без `!important`: `renderResult()` ставит инлайн
   `style.display = ""` (пустое значение не перекрывает класс),
   `renderNow()` ставит `none` — согласовано. При переключении режима
   на лету (`setTwoCol`/`recalcLayout`) правило применяется само,
   JS-правок не нужно.
3. JS (`renderResult`/`renderNow`/`scrollToSourceRow`) не трогать:
   логика показа/скрытия и скролла к строке остаётся прежней; 🔝 живёт
   в `btnrow`, поэтому виден только вместе с результатом — достаточно.

## Риски

- `alignResultToRow` в двухколоночном режиме скроллит так, что строка и
  результат видны одновременно — кнопка 🔙 там действительно лишняя.
- 🔝 использует `behavior:"smooth"` — в старых WebView без поддержки
  опций `scrollTo` молча деградирует до мгновенного перехода; оставить
  как есть.

   🔝 скроллит страницу наверх, 🔙 — к строке источника.
2. Широкое окно (двухколоночный режим): в панели только 🔝 (🔙 скрыт
   CSS-правилом); при переключении ширины/перетаскивании разделителя
   кнопка 🔙 появляется/исчезает без перезагрузки.
3. «Сейчас» (`renderNow`): 🔙 скрыта как раньше (инлайн `none`), 🔝 видна.
4. Синтаксис — правки декларативные; визуальная проверка в браузере.
