# План: тактильный отклик при срабатывании PTR (VK-режим)

**Дата:** 2026-09-03
**Файл:** `LunarReturns/index.html`

## Контекст

PTR в VK-режиме самописный (IIFE, index.html:448–506): жест при `scrollY<=0`, порог 70px, при отпускании с `dist >= THRESHOLD` — `location.reload()`.

**Момент отклика (уточнено):** в нативном Android Chrome тактильный сигнал срабатывает при пересечении порога **во время тяги** (взведение спиннера), не при отпускании; в iOS Safari отдачи нет вовсе. Повторяем метафору «взводится жест»: вибрация при первом достижении порога в `touchmove`, однократно на жест.

## Изменение

1. Добавить хелпер (внутрь PTR-IIFE, до листенеров):

```js
// Тактильный «толчок» при взводе PTR: taptic-ивент бриджа ВК (iOS) И
// navigator.vibrate (Android). Вызовы независимы: в VK-контексте vkBridge
// есть всегда, но taptic-ивент Android-клиент не поддержает, поэтому
// else-if оставлял реальную вибрацию недостижимой на Android. iOS же не
// имеет navigator.vibrate — двойного отклика не будет.
function ptrHaptic() {
    if (window.vkBridge && typeof vkBridge.send === "function") {
        vkBridge.send("VKWebAppTapticImpactOccurred", { style: "light" }).catch(() => {});
    }
    if (typeof navigator.vibrate === "function") {
        try { navigator.vibrate(10); } catch (e) {}
    }
}
```

2. В переменные состояния IIFE добавить `let hapticDone = false;`.

3. `touchstart` (ветка `if (armed)`): сбрасывать `hapticDone = false;`.

4. `touchmove`: после вычисления `dist` добавить

```js
if (dist >= THRESHOLD && !hapticDone) { hapticDone = true; ptrHaptic(); }
```

(до или сразу после установки transform). Флаг гарантирует один толчок на жест, даже если палец ходит вокруг порога туда-обратно.

5. `ptrEnd`/`touchcancel` — без отдачи (как в нативном PTR: отпускание — просто защёлкивание).

## Заметки

- Стиль `light` — короткий ненавязчивый толчок; если покажется слабым, поднять до `medium` (одно слово).
- Повторное пересечение порога в пределах одного жеста (dy колеблется вокруг 70px) — отдачи уже нет: `hapticDone` сбрасывается только на новом `touchstart`.
- `vkminiapp`-гейт уже есть у всего блока PTR — хелпер вне клиента ВК недостижим, фолбэк оставлен на случай бридж-недоступности внутри клиента.

## Валидация

1. Android, клиент ВК: тянуть медленно — в момент прохождения ~70px один короткий толчок; отпустить — reload; недотянуть до порога — тишина, контент вернулся.
2. Колебание тяги вокруг порога — толчок ровно один на жест; новый жест — новый толчок.
3. iOS клиент ВК: то же с taptic-откликом.
4. Мобильный браузер вне ВК (страница напрямую): PTR-блок неактивен (`!vkminiapp`), ничего не изменилось.
